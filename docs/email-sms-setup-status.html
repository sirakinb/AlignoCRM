Email & SMS setup status

Progress against the GoHighLevel-style plan (Gmail/Outlook connections, inbound sync, Twilio numbers, A2P 10DLC, toll-free verification). Generated from the current codebase.

Direction change (2026-08-07): Resend-first, OAuth connections shelved

Native Gmail/Outlook OAuth is shelved — Google's restricted-scope verification (CASA, ~$0.5–4.5k/yr + weeks) isn't worth it at this stage, and if native mailbox sync is ever needed the plan is Nylas (or similar) rather than our own Google app. All email now flows through Resend on contact.alignocrm.com with pretty reply aliases (<workspace>@contact.alignocrm.com instead of r+<token>@). The OAuth/sync backend code is kept dormant (tested, hidden in the UI, no scheduler).
